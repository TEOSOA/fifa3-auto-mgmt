# FiFAO3 Mgmt — วิธีใช้งาน (Windows)

โปรแกรมช่วยเล่น FIFA Online 3: เล่นลีก VS COM อัตโนมัติ และซื้อนักเตะตามระดับที่เลือก

> ⚠️ เวอร์ชันนี้ยัง **ไม่กดในเกมจริง** — หน้าจอ ตัวนับ และขั้นตอนทำงานครบ แต่ส่วนจับภาพจอ
> และคลิกในเกมยังเป็นโหมดสาธิต (ดูหัวข้อ "สิ่งที่ยังต้องทำ" ด้านล่าง)

---

## 1. สิ่งที่ต้องมี

- Windows 10 หรือ 11 (64 บิต)
- เกม FIFA Online 3 (หน้าต่างชื่อ `FIFA ONLINE3 - Developed by SPEARHEAD`, โปรแกรม `fifazf.exe`)
- ไม่ต้องติดตั้งอะไรเพิ่ม — ใช้ไฟล์ `FiFAO3Mgmt.exe` ไฟล์เดียว

## 2. เปิดโปรแกรม

1. ดับเบิลคลิก `FiFAO3Mgmt.exe`
2. Windows จะถามสิทธิ์ผู้ดูแล (Administrator) → กด **ใช่ / Yes**
   (ต้องใช้สิทธิ์นี้ เพราะเกมรันแบบ Administrator ถ้าไม่ให้ คลิกจะส่งไม่ถึงเกม)
3. ถ้า Windows SmartScreen ขึ้นว่า "Windows protected your PC" → กด **More info** → **Run anyway**
   (ขึ้นเพราะไฟล์ยังไม่ได้ลงลายเซ็นดิจิทัล)
4. มุมบนขวาเลือกภาษา **TH / EN / VI** ให้ตรงกับภาษาของเกม และปุ่ม ☀ สลับโหมดสว่าง/มืด

ป้ายบนสุดบอกสถานะ: จุดเขียว "เชื่อมต่อเกมแล้ว" พร้อมขนาดหน้าต่างเกม และป้าย **Admin**
(ถ้าขึ้น "ไม่ใช่ Admin" ให้ปิดแล้วเปิดใหม่ด้วยคลิกขวา → Run as administrator)

## 3. หน้า "ลีกอัตโนมัติ"

1. ในเกม เข้าหน้าเมนูหลักให้พร้อมเล่นลีก
2. ตั้ง **จำนวนรอบ** ที่ต้องการ (1–999) ด้วยปุ่ม − / +
3. เลือกสวิตช์:
   - **ซ่อนหน้าต่างเกม** — เกมยังทำงานอยู่เบื้องหลัง (ห้ามพับจอเกมเอง)
   - **ต่อสัญญานักเตะอัตโนมัติ** — ปิดไว้ = กด "ยกเลิก", เปิด = กด "ต่อสัญญา" (เสีย EP)
4. กด **เริ่มทำงาน** หรือกด **F8**
5. แถบ "ขั้นตอนปัจจุบัน" จะเดินตาม 7 ขั้น: VS COM → League → จำลองการแข่งขัน →
   รอจบเกม → ดูผล → เลือกรางวัลแบบสุ่ม → ต่อไป แล้วนับรอบเพิ่ม 1
6. หยุดเมื่อครบจำนวนรอบ หรือกด F8 อีกครั้ง

## 4. หน้า "ซื้อนักเตะ"

1. ในเกม เปิดหน้า **ตลาดแลกเปลี่ยน → ซื้อ → ผลการค้นหา** เอง (ค้นหานักเตะที่ต้องการไว้ก่อน)
2. ในโปรแกรม กดแท็บ **ซื้อนักเตะ**
3. ตั้งค่า:
   - **จำนวนที่ต้องการซื้อ** (เริ่มต้น 5)
   - **มองหาระดับ** — เลือก +1 ถึง +10 (ซื้อเฉพาะนักเตะที่ป้ายระดับตรงกับที่เลือก)
   - **ซื้อครบแล้วไปหน้าอัปเกรด** — เปิดไว้ เมื่อซื้อครบจะพาไป
     Team → จัดการทีม → จัดการนักเตะ → ระดับ ให้อัตโนมัติ
4. กด **เริ่มทำงาน** หรือ **F8**
5. ทุกครั้งที่ซื้อสำเร็จ ตัวนับจะขึ้น เช่น **1 / 5**, **2 / 5** … ขั้นตอนต่อการซื้อ 1 ตัว:
   หานักเตะระดับที่เลือก → เลือกนักเตะ → กดซื้อ → ยืนยันการซื้อ → ยอมรับ
6. ปุ่ม **รีเซ็ตจำนวน** ตั้งตัวนับกลับเป็น 0

> กด F8 จะเริ่ม/หยุดเฉพาะหน้าที่เปิดอยู่ และถ้าเริ่มหน้าหนึ่ง อีกหน้าจะหยุดเอง (ใช้เกมเดียวกัน)

## 5. ระบบหยุดเอง

- ไม่มีความคืบหน้าเกิน **5 นาที** → หยุด (ป้องกันค้าง)
- กดปุ่มเดิมซ้ำ **8 ครั้ง** แล้วปุ่มไม่หายไป และค้างอยู่นานอย่างน้อย **60 วินาที** → หยุด
  (เก็บภาพหน้าจอตอนค้างไว้ล่าสุด 20 ภาพ เพื่อดูว่าค้างที่หน้าไหน)
- กดไปแล้ว **3 ครั้ง** แต่จอไม่เปลี่ยน → ขยับเมาส์จริงหนึ่งครั้งเพื่อปลุกเกม แล้วทำต่อ

## 6. ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| ภาษาไทย/เวียดนามเป็นสี่เหลี่ยม | ไม่ควรเกิดแล้ว (ฝังฟอนต์ Prompt ไว้ในโปรแกรม) ถ้ายังเป็น ให้แจ้งพร้อมภาพ |
| ป้ายขึ้น "ไม่ใช่ Admin" | คลิกขวาที่ไฟล์ → Run as administrator |
| หน้าต่างเกมแคบกว่า 4:3 | ปุ่มด้านขวาของเกมอาจถูกตัด ให้ขยายหน้าต่างเกมให้กว้างขึ้น |
| เลือกภาษาไม่ตรงกับเกม | ต้องเลือกภาษาในโปรแกรมให้ตรงกับเกม เพราะรูปปุ่มแยกตามภาษา |

## 7. สำหรับนักพัฒนา

- ถ่ายภาพหน้าจอโปรแกรมแล้วปิดเอง: `FiFAO3Mgmt.exe --screenshot ภาพ.png`
- เปิดที่หน้าซื้อนักเตะทันที: `FiFAO3Mgmt.exe --page buy`

### สิ่งที่ยังต้องทำ

- จับภาพหน้าต่างเกม + หาปุ่มด้วยรูป (template matching) + ส่งคลิกเข้าเกม
- รูปปุ่มของหน้า "ซื้อนักเตะ" และทาง "ไปหน้าอัปเกรด" (ต้องตัดจากเกมของคุณเอง)
- ค่าตั้งของหน้า "ซื้อนักเตะ" เป็นค่าประมาณ (โปรแกรมเดิมไม่มีฟีเจอร์นี้)

## 8. ไฟล์ที่ควรนำขึ้น GitHub

นำขึ้น (โค้ดและไฟล์ที่ใช้สร้างโปรแกรม):

| ไฟล์ / โฟลเดอร์ | คืออะไร |
|---|---|
| `src/` | โค้ดโปรแกรมทั้งหมด (หน้าจอ, ลีกอัตโนมัติ, ซื้อนักเตะ, ส่วนหาปุ่ม) |
| `Cargo.toml` | ชื่อโปรเจกต์และไลบรารีที่ใช้ |
| `Cargo.lock` | ล็อกเวอร์ชันไลบรารี ให้สร้างได้ผลเหมือนเดิม |
| `build.rs` | ฝังไอคอน/สิทธิ์ Administrator ตอนสร้างไฟล์ .exe |
| `windows-res/` | ไฟล์ manifest (ขอสิทธิ์ Admin) และ app.rc |
| `.cargo/config.toml` | ตั้งค่าการสร้าง .exe สำหรับ Windows |
| `assets/fonts/` | ฟอนต์ Prompt + ใบอนุญาต `Prompt-OFL.txt` (ต้องเอาขึ้นด้วยกัน) |
| `README.md` | คำอธิบายโปรเจกต์ |
| `MECHANICS.md`, `mechanics.json` | ค่าและกฎที่ถอดจากโปรแกรมเดิม |
| `windows/README.md` | ไฟล์นี้ (วิธีใช้งาน) |
| `.gitignore` | บอก git ว่าไม่ต้องเอาไฟล์ไหนขึ้น |

ไม่ต้องนำขึ้น (มีใน `.gitignore` แล้ว):

| ไฟล์ / โฟลเดอร์ | เหตุผล |
|---|---|
| `target/` | ผลการคอมไพล์ ใหญ่มาก สร้างใหม่ได้เสมอ |
| `shots/` | ภาพหน้าจอทดสอบ |
| `.DS_Store` | ไฟล์ระบบของ macOS |
| `windows/FiFAO3Mgmt.exe` | ไฟล์โปรแกรม (~18 MB) — แนะนำแนบใน **GitHub Releases** แทน |

ข้อควรระวัง:
- **ห้าม**นำโปรแกรมเดิม (FO3AutoLeague.exe) หรือรูปปุ่ม/โลโก้ที่ตัดจากเกมขึ้น GitHub สาธารณะ
  เพราะเป็นลิขสิทธิ์ของผู้อื่น
- สร้าง .exe ใหม่จากโค้ด: `cargo build --release --target x86_64-pc-windows-gnu`
  ไฟล์จะอยู่ที่ `target/x86_64-pc-windows-gnu/release/FiFAO3Mgmt.exe`

ขั้นตอนเอาขึ้นครั้งแรก (ในโฟลเดอร์โปรเจกต์):

```
git init
git add .
git commit -m "FiFAO3 Mgmt v1.6"
git branch -M main
git remote add origin https://github.com/<ชื่อคุณ>/fifao3-mgmt.git
git push -u origin main
```
