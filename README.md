# FO3 Auto League v1.6 — คู่มือใช้งาน

โปรแกรมช่วยเล่น **FIFA Online 3 (เวอร์ชันไทย)** โดยเล่นโหมด **ลีก (VS COM)**
ให้แบบอัตโนมัติ — เขียนใหม่ด้วยภาษา **Rust** พร้อมกรอบ GUI **eframe/egui**

> โปรแกรมนี้ช่วยเล่นให้ในโหมดลีก VS COM (แข่งกับคอม) เท่านั้น
> ใช้งานให้เป็นไปตามเงื่อนไขของเกมที่กำหนด และด้วยความรับผิดชอบของคุณเอง

---

## การใช้งาน

### หน้าต่างหลัก

| ชิ้นส่วน | คำอธิบาย |
|---|---|
| **โลโก้ FO3 AUTO LEAGUE** | แสดงด้านบนของหน้าต่าง |
| **เลือกภาษา** | ไทย / English / Tiếng Việt — คลิกเพื่อเปลี่ยนภาษาได้ทันที |
| **ปุ่ม เริ่มทำงาน / หยุด** | ปุ่มใหญ่สีเขียวกึ่งกลาง — คลิกเพื่อเริ่ม หรือเริ่มแล้วคลิกเพื่อหยุด |
| **F8** | กดคีย์ **F8** เพื่อเริ่ม / หยุด ได้เหมือนคลิกปุ่ม |
| **ซ่อนหน้าต่างเกม** | สวิตช์ซ่อนหน้าต่างเกม (อย่าย่อหน้าต่างเกมเอง — ให้ใช้สวิตช์นี้) |
| **ต่อสัญญานักเตะอัตโนมัติ** | ปิดเป็นค่าเริ่มต้น — เปิดใช้แล้วจะหัก **EP** ในเกมต่อสัญญา |
| **แถบความคืบหน้า** | แสดงนาทีของแมตช์ (15:00) และเปอร์เซ็นต์ขณะกำลังเล่น |
| **ประวัติ (Log)** | แสดงเหตุการณ์ล่าสุด เช่น เริ่ม/หยุด แมตช์จบ ต่อสัญญา |

### ขั้นตอนการเริ่มเล่น

1. เปิดโปรแกรม (ถ้า Windows ถาม UAC ให้กด **Yes** — โปรแกรมต้องการสิทธิ์ผู้ดูแลระบบ)
2. เปิดเกม FIFA Online 3 และเข้าสู่โหมดลีก (VS COM)
3. เลือกภาษาที่ต้องการ
4. คลิก **เริ่มทำงาน** หรือกด **F8** — ปุ่มจะเปลี่ยนเป็นสีแดง (หยุด)
5. กด **F8** อีกครั้งเพื่อหยุด

> **หมายเหตุโหมดสาธิต**: ตัวโปรแกรมนี้เป็นฐานให้ท่านนำไปพัฒนาต่อ —
> ยังไม่ได้ต่อเข้ากับเกมจริงบนทุกแพลตฟอร์ม
> บน Windows ให้ใส่คำสั่งควบคุมเกม (เมาส์/คีย์บอร์ด) ในไฟล์ `src/backend.rs`
> ตามจุดที่เขียนว่า `TODO(you)` (ดู `MECHANICS.md` สำหรับรายละเอียด)

## วิธี Build และใช้งานบน Windows 10/11

### วิธีที่ 1: สร้างเองจากโค้ด (แนะนำสำหรับนำไปพัฒนาต่อ)

#### ขั้นตอนที่ 1 ติดตั้ง Rust (ตัวแปลภาษา)

1. เข้าเว็บ <https://www.rustup.rs> แล้วดาวน์โหลด `rustup-init.exe`
2. รัน `rustup-init.exe` แล้วกด **1) Proceed with standard installation**
3. ปิดและเปิดหน้าต่าง Command Prompt / PowerShell ใหม่ แล้วทดสอบ:

   ```
   rustc --version
   cargo --version
   ```

   ถ้าแสดงเวอร์ชัน (เช่น 1.99.1) ถือว่าติดตั้งสำเร็จ

#### ขั้นตอนที่ 2 นำโค้ดโปรแกรมไป

คัดลอกโฟลเดอร์ `app/` ทั้งโฟลเดอร์ไปไว้เครื่อง Windows (ต้องมีไฟล์ `Cargo.toml`
และโฟลเดอร์ `src/` อยู่ข้างกัน)

#### ขั้นตอนที่ 3 สร้าง (build)

เปิด Command Prompt หรือ PowerShell แล้วไปที่โฟลเดอร์ `app/`:

```
cd C:\path\to\app
cargo build --release
```

ครั้งแรกจะดาวน์โหลดและคอมไพล์ไลบรารี ใช้เวลาประมาณ 1–3 นาที
ไฟล์ที่สร้างได้: `target\release\FO3AutoLeague.exe`

#### ขั้นตอนที่ 4 รัน

```
target\release\FO3AutoLeague.exe
```

หรือดับเบิลคลิก `FO3AutoLeague.exe` โดยตรงก็ได้

> ทดสอบหน้าตาโปรแกรมโดยไม่เปิดหน้าต่าง:
> `target\release\FO3AutoLeague.exe --screenshot C:\shots\now.png`
> (จะบันทึกภาพหน้าจอโปรแกรมเป็นไฟล์ PNG แล้วจบ)

### วิธีที่ 2: สร้างไฟล์ .exe ไฟล์เดียว (ส่งต่อให้คนอื่นได้)

ติดตั้งเครื่องมือ [Nix package manager](https://nixos.org/download.html) (ไม่บังคับ)
หรือใช้วิธีง่ายกว่า — สร้างไฟล์ .exe แบบ "portable" ด้วย `cargo-bundle` ไม่ได้เหมาะกับ
Windows ตรงๆ ดังนั้นวิธีที่นิยมที่สุดคือ:

1. ติดตั้ง Rust แบบ stable ตามขั้นตอนที่ 1
2. Build ตาม `cargo build --release`
3. คัดลอก `target\release\FO3AutoLeague.exe` ไปไว้ในโฟลเดอร์เดียว
   (โปรแกรมนี้สร้างเป็นไฟล์เดียวอยู่แล้ว ไม่จำเป็นต้อง copy ไลบรารีอื่น)
4. ส่งโฟลเดอร์นั้นให้ผู้อื่นรันบน Windows 10/11 (ต้องใช้ Rust ในเครื่องของ
   ผู้รันด้วยหรือไม่ — **ไม่จำเป็น**: ไฟล์ .exe แบบ release รันได้เอง
   ถ้าผู้รันไม่มี Rust ก็รันได้ปกติ)

> ถ้าต้องการฝังไอคอน/สิทธิ์ Administrator ลงใน .exe ให้ใช้
> [editbin/WinFsp](https://winscp.net/) หรือ Rust crate `embed-resource`
> เพิ่มภายหลัง

### ปัญหาที่พบบ่อย (Windows)

| อาการ | วิธีแก้ |
|---|---|
| `rustc` ไม่พบ / ไม่ใช่คำสั่งภายในที่ถูกต้อง | ติดตั้ง Rust ไม่สมบูรณ์ — ปิดแล้วเปิด PowerShell ใหม่ หรือลอง reinstall |
| `cargo build` ผิด `failed to run custom build command` | ติดตั้ง **Visual Studio Build Tools** (Component "Desktop development with C++") แล้วลองใหม่ |
| โปรแกรมไม่แสดงหน้าต่าง | Windows อาจถาม UAC — กด Yes หรือ run as administrator |
| F8 ไม่ทำงาน | บางเกม/โปรแกรมกินคีย์ F8 ไว้ — ใช้ปุ่ม "เริ่มทำงาน" แทน |
| สวิตช์ซ่อนหน้าต่างเกมไม่ทำงาน | ยังไม่ได้ต่อ backend ใน `src/backend.rs` — เป็นจุด `TODO(you)` |

## การนำไปพัฒนาต่อ

| ไฟล์ | หน้าที่ |
|---|---|
| `src/main.rs` | จุดเริ่ม, รับคำสั่งบรรทัดคำสั่ง (`--screenshot`), สลับภาษา F8 |
| `src/ui.rs` | หน้าต่าง, ข้อความ 3 ภาษา (ไทย/อังกฤษ/เวียดนาม), ปุ่มเริ่ม/หยุด |
| `src/automation.rs` | วงจรทำงาน (tick, เปลี่ยนแมตช์, ต่อสัญญา) — ปรับเวลาได้จากค่าคงที่ด้านบน |
| `src/backend.rs` | **จุดต่อเข้าเกมจริง** (Windows: `ShowWindow` ซ่อนหน้าต่าง, `SendInput` ส่งคำสั่ง) |
| `MECHANICS.md` | รายละเอียดค่าที่ถอดจากโปรแกรมเดิม + ค่าประมาณ (ดูว่าค่าไหนยืนยันแล้ว ค่าไหนประมาณ) |
| `mechanics.json` | ค่าเดียวกันในแบบ JSON สำหรับอ่านด้วยโปรแกรม |

### ตัวอย่างจุดที่ควรต่อเข้าเกมจริง (ใน `src/backend.rs`)

```rust
// 1. ค้นหาหน้าต่างเกม: FindWindowW(NULL, L"FIFA Online 3")
// 2. ซ่อน/แสดง: ShowWindow(hwnd, SW_HIDE / SW_SHOW)
// 3. ส่งคำสั่งเมาส์/คีย์: SendInput(...)
// 4. อ่านสถานะ (ถ้าต้องการ): ReadProcessMemory / การจับภาพหน้าจอ
```
